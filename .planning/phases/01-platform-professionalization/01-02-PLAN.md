<objective>
Fix the suspension race condition (PROF-04) by moving the suspension check out of ProtectedRoute and into useAuth. This eliminates the one-render-cycle window where a suspended user can briefly see protected content.

Purpose: The root cause is that ProtectedRoute runs its own Supabase query in a useEffect, creating a gap between "user is set" and "suspension is checked". Moving the check into useAuth's existing fetchRoleAndProfile call makes it atomic — either all auth state (role + profile flags + suspended) loads together, or none does.
Output: useAuth exports suspended, ProtectedRoute reads it directly.
</objective>
